## 七、注释规范总结

### 文件头注释模板

所有前端文件都应包含以下结构的文件头注释：

```typescript
/**
 * [文件名] - [功能简述]
 * 
 * 核心职责：
 * - 职责 1
 * - 职责 2
 * - 职责 3
 * 
 * 工作流程：
 * 1. 步骤 1 说明
 * 2. 步骤 2 说明
 * 3. 步骤 3 说明
 * 
 * 关键特性：
 * - 特性 1 及其意义
 * - 特性 2 及其意义
 * 
 * 设计考虑：
 * - 考虑 1
 * - 考虑 2
 * 
 * @component
 */
```

### Props 注释规范

所有 Props 接口都应有完整的类型和用途说明：

```typescript
interface ComponentProps {
  /** 属性简述 - 用途和约束条件 */
  prop1: string;
  
  /** 
   * 复杂属性说明
   * - 选项 1：说明
   * - 选项 2：说明
   */
  prop2: 'option1' | 'option2';
}
```

## 八、团队建议

### 对新手开发者的建议

1. **从 types/index.ts 开始**：理解所有数据结构
2. **学习 lib/ 目录**：理解 API 层和工具函数
3. **学习 context/ 和 hooks/**：理解状态管理模式
4. **再学习 components/**：从简单组件（common）→ 复杂组件（media）
5. **最后学习 app/**：理解页面层和路由

### 代码审查建议

- 新 PR 提交前必须检查是否有过时的注释
- 修改重要逻辑时必须更新对应的注释
- 新功能必须包含完整的文件头注释和 Props 文档
- 定期（每个月）检查一次注释的准确性
